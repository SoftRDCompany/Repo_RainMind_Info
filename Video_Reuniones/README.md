### Descripción
Durante la reunión se presentó RainMinds, una iniciativa de SoftRD enfocada en desarrollar habilidades técnicas mediante el aprendizaje práctico y el trabajo colaborativo.

Se explicó que el primer proyecto será Educando, una plataforma que se desarrollará por metas y entregables, con actividades de análisis, programación, documentación y revisión. Se utilizarán herramientas como GitHub para organizar el código y LinkedIn para compartir los avances profesionales.

El programa tendrá una duración aproximada de un año y busca que los participantes adquieran experiencia en proyectos reales, sin descuidar sus estudios universitarios. También se informó que la participación no será remunerada por el momento y que se proporcionará un documento de confidencialidad y propiedad intelectual para su revisión y firma.

Finalmente, se indicó que las metas, los materiales y las fechas de trabajo se publicarán en la plataforma de RainMinds, mientras que WhatsApp se utilizará para comunicar avisos importantes.
